# Third-party code, data and credits

SevenSynthCore contains or links code and data written by other people. This file lists each piece, its author, its licence
and where it lives in the tree. **Keep it current**: when code is copied, ported or generated from someone else's work, add an
entry here and keep the original notice in the source files (a ported file keeps a header naming the author and the licence).
A firmware or simulator binary is a copy too: the notices below must ship with any binary that is distributed.

## Mutable Instruments DSP code: Émilie Gillet

The Braids and Plaits oscillator models and the stmlib DSP helpers are the work of **Émilie Gillet** (Mutable Instruments),
released under the MIT licence. Thank you, Émilie, for publishing them.

## Data and algorithms from other projects

| What | Where | Origin and licence |
|---|---|---|
| DX7 factory patches (128) and the 32 FM algorithm wirings, generated into C | `src/core/dx7_factory.c`, `src/core/dx7_algos.c`, `tools/gen_dx7.py`; wiring used in `src/engine/modules/dx7_voice.cpp` | AMY (shorepine/amy, Brian Whitman and Dan Ellis), MIT. The wiring tables come from MSFA (Google, Apache 2.0) through AMY; the patches are Yamaha's DX7 ROM data. **To verify:** AMY's exact copyright line (the AMY sources are no longer in `lib/`). |
| ESP32-S3 PIE FFT stages: the loop structure (radix-2 stages with bit-reversed twiddles, the PIE complex multiply / butterfly sequence, the special last two stages); our code adds the per-stage block floating point shift, the max / min tracking, q14 twiddles and the pack kernel | `src/engine/dsp/fft_s3.S` | Espressif ESP-DSP `dsps_fft2r_sc16_aes3` (Espressif Systems, Apache 2.0); written after reading its disassembly, no source copied. The boot benchmark (`bench_esp32.cpp`, dev only) also links ESP-DSP's FFTs from the Arduino framework for comparison. |
| Plate reverb topology and tap table (our implementation) | `src/engine/modules/fx_modules.cpp` (Reverb) | J. Dattorro, "Effect Design, Part 1", JAES 1997 (a published algorithm, credited; no code copied) |
