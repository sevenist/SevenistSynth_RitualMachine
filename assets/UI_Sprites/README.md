# UI sprites

Source images for the screen's sprites (icons, module pictures, UI elements). They will be turned into a generated C header by the
build (see "UI sprites build" in CONTINUE.md's todo): nothing in this folder is read by the firmware or the simulator directly.

Not decided yet (to settle when the converter is written): the image format (PNG, 1-bit or a threshold on grey), the naming rule
(file name = sprite name), sub-folders per kind, and how animation frames are named.
